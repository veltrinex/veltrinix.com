# Veltrinex New Joiner Onboarding Guide (Internal)

## Company Email
- Domain: veltrinex.com
- Format: `role@veltrinex.com` or `firstname.lastname@veltrinex.com`
- Examples: `webadmin@veltrinex.com`, `john.doe@veltrinex.com`

## Temporary Password (All New Accounts)

## Web Administrator Access
1. Sysadmin creates your mailbox (`webadmin@veltrinex.com`)
2. You will receive an email from sysadmin containing:
   - WordPress admin URL
   - Admin username and password
3. **WordPress URL**: https://wordpress.local  
   Login page: https://wordpress.local/wp-admin
