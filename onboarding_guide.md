# Veltrinex New Joiner Onboarding Guide (Internal)

## Company Email
- Domain: veltrinex.com
- Format: `firstname.lastname@veltrinex.com`
- Examples: `john.doe@veltrinex.com`

## Temporary Password (All New Accounts)

## Web Administrator Access
1. Sysadmin creates your mailbox (`fname.lname@veltrinex.com`)
2. You will receive an email from sysadmin containing:
   - WordPress admin URL
   - Admin username and password
3. **WordPress URL**: https://veltrinex.com
   Login page: https://veltrinex.com/wp-admin
